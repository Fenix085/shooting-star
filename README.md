# shooting-star
CLI tool for searching anime, viewing information cards, and exploring (currently only sequel) relationships using the AniList API


## Requirements

- Python 3.13 or later
- [uv](https://docs.astral.sh/uv/)

## Install and run from source

```bash
git clone https://github.com/Fenix085/shooting-star.git
cd shooting-star
uv sync
uv run shooting-star
